# Ruumy

**A link becomes a live space where people can meet, think, and build together.**

We're building the live layer of the web — real-time collaborative rooms that anyone can open and share instantly, with zero friction and zero installation.

---

## What we're building

A shared URL becomes a live space : presence, chat, canvas, collaboration.  
No account required. No app to download. Just a link.

```
join.ruumy.xyz/R0om1  →  a live room, instantly
```
